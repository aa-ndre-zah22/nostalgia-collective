# 🎵 NOSTALGIA COLLECTIVE - Project Brief

## Project Name & Concept
**NOSTALGIA COLLECTIVE** - A social-collaborative platform where people remix childhood sounds, draw shared memories, and connect through immersive collaborative sessions.

### Tagline
*"Mix sounds. Draw memories. Connect across time."*

---

## Problem Statement
People feel disconnected from the sensory memories of their childhood. Sounds trigger nostalgia but there's no platform to:
- Recreate those soundscapes with others
- Share the visual/emotional context through drawing
- Collaborate in real-time with people who had similar experiences
- Build community around shared cultural touchstones

---

## Core Solution
A three-pillar experience:

### 1. **Sound Mixer** 🎚️
Mix childhood sounds into personalized soundscapes

### 2. **Memory Drawing** 🎨
Add collaborative drawings to contextualize sounds

### 3. **Live Collaboration** 🎥
Connect via video calls to draw together while listening

---

## Target Users
- **Age**: 18-45 (strong nostalgia cohort)
- **Mindset**: People seeking connection through shared cultural experiences
- **Geographic**: Initially South Asia (India focus), expandable globally
- **Use Cases**:
  - Solo memory creation (5-10 mins)
  - Collaborative drawing sessions (15-30 mins)
  - Browsing & discovering others' memories (casual)

---

## Key Features (MVP)

### User Journey: Create → Draw → Collaborate → Share

1. **Sound Mixer**
   - Select 3-5 childhood sounds
   - Adjust volume/timing
   - Preview mix

2. **Memory Canvas**
   - Add drawing (free-form or guided)
   - Write memory note (100-500 chars)
   - Tag decade/country/theme

3. **Publish & Share**
   - Generate shareable link
   - Preview card (sound + image + text)

4. **Collaborative Sessions**
   - Host live drawing room
   - Video + shared canvas
   - Invite friends/strangers with similar memories
   - Export final drawing + sound mix

5. **Discovery & Connection**
   - Browse memory gallery
   - Filter by: decade, region, sound, theme
   - Like/comment/remix
   - "Similar memories" suggestions
   - Create memory bundles
